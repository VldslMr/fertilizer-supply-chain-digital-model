# Справочники для модели транспортных затрат

Небольшие таблицы с постоянными параметрами. Хранятся в git (в отличие от сырых данных).
У каждой цифры есть источник; `is_estimate = True` — наша оценка, её стоит уточнить.

| Файл | Что внутри | Как получен |
|---|---|---|
| `routes.csv` | морские расстояния порт → порт, сценарии `normal` и `no_red_sea` (обход вокруг Африки), через какие проливы идёт путь | `python src/reference/build_routes.py` (библиотека searoute, морская сеть MARNET) |
| `vessel_classes.csv` | Handysize / Supramax / Ultramax: дедвейт, партия, скорость, расход топлива | отраслевые источники + оценки |
| `plants.csv` | крупные экспортные заводы карбамида: мощность, порт, идёт ли отгрузка через Ормуз | отчёты и пресса компаний |
| `charter_rates.csv` | точки «BDI ↔ ставка аренды Supramax/Handysize, $/день» для перевода индекса в ставку: Supramax ≈ 3 790 + 6.1 × BDI (3 точки  грубо; проверено вручную 04.11.2026) | handybulk.com (данные Baltic Exchange) |
| `fees.csv` | военная страховка, сбор Суэца, портовые сборы, скорость погрузки/выгрузки, ожидание | S&P Global Platts (страховка), остальное — оценки |

Важно:
- Порт Сур (OMIFCO, Оман) — **снаружи** Ормузского пролива, Катар и Джубайль — внутри. При закрытии Ормуза поток из залива не обходится, а блокируется.
- Военная страховка в Персидском заливе выросла с 0,05–0,07 % стоимости судна (2024–2025) до 7,5–10 % (июль 2026). Для Supramax стоимостью $20–27 млн это ~$43–58/т — больше, чем весь фрахт в спокойное время.
