# Чекпоинт 2 — транспортные затраты

Автор: Степан Минаков. Тема 171, «цифровой двойник» цепочки поставок карбамида.

Задача: сколько судов нужно заводу в год, сколько стоит их аренда, как это зависит от выпуска и где «бутылочное горлышко», ограничивающее прибыль. Связь с таргетом: цена FOB = цена покупателя − фрахт (netback), поэтому стоимость доставки — признак для модели надбавки.

## Главные результаты
- Доставка из Катара в 2025 г. ≈ $40/т (от ~$12 до Индии до ~$57 до США).
- Модель совпадает с фактом Comtrade (CIF − FOB): корреляция 0,89 по годам.
- Стоимость тонны не зависит от выпуска завода; выпуск определяет число судов (~24 Supramax на 6 млн т QAFCO).
- 2026: горлышко — Ормуз; военная страховка выросла с 0,05–0,07 % до 7,5–10 % стоимости судна (≈40 % стоимости доставки).
- Признак `transport_cost_per_t` сохраняется в `data/processed/transport_cost_monthly.parquet` (для чекпоинта 3).

## Главные выводы EDA (`03_eda_transport.ipynb`)
- Уровень `transport_cost_per_t` нестационарен, его изменения стационарны: в модель подавать `d_tc` / `r_tc`.
- Изменение доставки опережает изменение надбавки на 2–3 месяца (корреляция ≈ −0,25, граница случайности 0,17), знак соответствует FOB = CIF − фрахт. Обратной связи нет.
- Сигнал в основном нефтяной (топливо); чистая аренда по BDI статистически не значима.
- Поверх газа и Brent доставка в линейной модели ничего не добавляет (скорректированный R² 0,817 → 0,817). Заметного прироста качества ждать не стоит.
- Военная страховка в ряду — три сценарных уровня, а не наблюдаемые данные; в 2026 году всего 9 наблюдений.

## Формат таблицы признаков
`data/processed/transport_cost_monthly.parquet` — под склейку с признаками команды:
- колонка `date` — первое число месяца (`2015-04-01`), период апрель 2015 — сентябрь 2026 (138 месяцев, без пропусков);
- признаки: `transport_cost_per_t` (итого, $/т), составляющие `hire`, `fuel`, `fees`, `war` ($/т), `T_days` (время рейса, дни), `bdi_avg`;
- чужие колонки (`brent`, `urea_price`) не включены.

**`bdi_avg` — оценка, а не настоящее среднее.** Barchart отдаёт только месячные свечи, дневных данных у нас нет, поэтому среднее за месяц оценено как (open + close) / 2. Если появится дневной ряд BDI, заменить на `resample("MS").mean()` в `src/data/load_bdi.py` и перезапустить ноутбук. Это сдвигает результаты незначительно: корзина Катара 2025 г. $39,8/т (раньше $40,1 по значению на конец месяца), корреляция с Comtrade 0,89.

Для команды в git лежит CSV-копия: [`data/processed/transport_cost_monthly.csv`](data/processed/transport_cost_monthly.csv) (те же данные, что в parquet). Остальное в `data/processed/` в git не хранится, его создаёт ноутбук.

## Как запустить
Все пути относительные от этой папки (`checkpoint_2/transport_costs/`).

```bash
pip3 install pandas pyarrow matplotlib searoute
cd checkpoint_2/transport_costs
# 1. сырые данные положить в data/raw/ (список файлов — в шапках load_comtrade.py и load_bdi.py)
python3 src/data/load_comtrade.py
python3 src/data/load_bdi.py
# 2. открыть notebooks/02_transport_costs.ipynb и выполнить все ячейки
```

Сырые и обработанные данные (`data/raw/`, `data/processed/`) в git не хранятся, это задумано (`.gitignore` в этой папке).

**Зависимость от чужой части:** ноутбук читает `data/processed/prices_monthly.parquet` — его строит `src/data/load_pink_sheet.py` Елизаветы Штуцы из World Bank Pink Sheet. Скрипт сюда не копировался.
